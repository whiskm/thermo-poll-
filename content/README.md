# Контент ТермоОпроса

- `questions.json`: 69 вопросов, ответы, формулы, ключевые термины, ссылки на схемы.
- `diagrams/`: 50 схем в SVG. Цвет осей и подписей берется из `currentColor`.
- `../scripts/diagrams.py`: генератор схем (`pip install iapws && python3 scripts/diagrams.py`).

## Поля вопроса

| Поле | Содержимое |
|---|---|
| `id` | Номер вопроса из списка преподавателя, 1-69 |
| `section` | Раздел: `basics`, `gases`, `process`, `steam`, `air`, `cycles` |
| `short` | Короткое название для списка |
| `question` | Полный текст вопроса |
| `answer` | Ответ, разбитый на 3-5 предложений |
| `formulas` | Ключевые формулы в LaTeX для шпаргалки |
| `keyTerms` | Термины из текста ответа для режимов «Пропуски» и «Свой ответ» |
| `diagrams` | Схемы: файл в `diagrams/` и подпись |

Формулы внутри текста записаны между знаками `$` и выводятся через KaTeX.
