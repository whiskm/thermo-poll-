# Публикация на Cloudflare Pages

Сайт собирается на Cloudflare из ветки `main`: каждый пуш в `main` обновляет сайт примерно за 1-2 минуты.

## Перед подключением

Код приложения должен быть в ветке `main`. Если `main` пустая, первая сборка на Cloudflare упадет с ошибкой «нет package.json».

## Подключение (один раз, около 5 минут)

1. Войдите на dash.cloudflare.com.
2. В меню слева откройте «Workers & Pages» (в русском интерфейсе «Workers и Pages»).
3. Нажмите «Create» (Создать) и выберите вкладку «Pages». Если открылось создание Worker, внизу страницы есть ссылка на Pages.
4. Нажмите «Import an existing Git repository» (Подключить Git).
5. Выберите GitHub и разрешите Cloudflare доступ к репозиторию `whiskm/thermo-poll-`. Достаточно доступа только к этому репозиторию.
6. Выберите репозиторий `thermo-poll-` и нажмите «Begin setup».
7. Заполните настройки сборки:

| Поле | Значение |
|---|---|
| Project name | `termoopros` (станет адресом `termoopros.pages.dev`; если имя занято, подойдет любое латиницей) |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `npm run build` |
| Build output directory | `dist` |

8. Нажмите «Save and Deploy» и дождитесь зеленой отметки «Success».
9. Сайт откроется по адресу `https://termoopros.pages.dev` (или с вашим именем проекта).

Версию Node.js задает файл `.nvmrc` (22), отдельная переменная окружения не нужна.

## Как установить на телефон

- Android, Chrome: откройте сайт, меню «⋮», «Добавить на главный экран» или «Установить приложение».
- iPhone, Safari: кнопка «Поделиться», «На экран Домой».

После первого открытия приложение работает без интернета.

## Проверка после публикации

1. Сайт открывается, на главной видна термокарта из 69 клеток.
2. В вопросе № 52 видны 3 схемы и формулы.
3. Включите режим полета и перезагрузите страницу: приложение открывается.

## Если сборка упала

Откройте проект в Cloudflare, вкладку «Deployments», последнюю сборку и журнал «Build log». Последние 30 строк журнала достаточно прислать в чат.
