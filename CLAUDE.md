# Правила работы

## Сначала обсуждение, потом код

1. Любая новая задача начинается с обсуждения: уточняющие вопросы и варианты решения.
2. По итогам обсуждения составляется ТЗ: цель, объём работ, затрагиваемые файлы, критерии готовности.
3. Код, файлы и коммиты появляются только после явного одобрения ТЗ пользователем.
4. Если по ходу работы нужно выйти за рамки одобренного ТЗ, работа останавливается до нового обсуждения и одобрения.
